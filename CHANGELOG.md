# Changelog

## 0.1.0 — 2026-09-14

- Local network incident capture with bounded prehistory, debouncing, recovery merge, and interrupted checkpoints.
- Independent gateway, TCP/IP, DNS, TLS/HTTP, and event-driven path observations.
- Deterministic evidence-based classification, family-aware degradation, and rolling latency baseline.
- Network-change/resume events, read-only platform adapters, capability gaps, and watcher locking.
- Offline sanitized HTML, Markdown, CSV, and versioned JSON alongside raw local evidence.
- CLI commands, reproducible offline demo, English/Russian documentation, and a 3-OS × 3-Python CI matrix.
- Native Windows validation and a regression fix for false route-change incidents caused by volatile route-table metadata.

See the [validation record](docs/validation.md) for the completed release checks and remaining platform caveats.
